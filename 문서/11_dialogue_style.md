# 대사 번역 참조표 — 인명·어투·제약 (2026-08-16)

이벤트 대사 5,470줄을 번역할 때 **여기 적힌 것만 따른다.** 줄마다 즉흥으로
정하면 같은 인물이 장면마다 다른 말투를 쓰게 된다.

작업 순서는 `docs/09_handoff.md` §2 참조:
**추출 → (여기) 어투표 → 번역 → 전수 검토 → 글리프·길이 확보 → 반영.**

## 0. 마스터 파일

`assets/translations/event_master.tsv` — 5,470줄. `scripts/evexport.py` 가 만든다.

```bash
python scripts/evexport.py "roms/Star Ocean - Blue Sphere (Japan).gbc" \
    -o assets/translations/event_master.tsv --carry assets/translations/event_master.tsv
```

`--carry` 로 **이미 채운 `ko` 를 이어받는다** — 다시 뽑아도 번역이 날아가지 않는다.

⛔ **앞 세 열은 `key` / `jp` / `ko` 고정.** `check_tr`·`alloc_glyphs`·`evrepack`
은 헤더가 아니라 **위치**(f[0],f[1],f[2])로 읽는다. 순서를 바꾸면 엉뚱한 열을
번역문으로 읽고도 조용히 돈다(실제로 `cpu` 열을 번역문으로 읽은 적이 있다).

| 열 | 쓰임 |
|---|---|
| `budget` | 스텁이 들어갈 자리(=`1+bytes`). **4 미만이면 못 바꾼다**(`stub=SHORT`, 55줄) |
| `speaker` | 화자. 아래 §1 |
| `slot` | 파티원별 변형에서 **몇 번째 갈래**인가 |
| `scene` | 이 대사에 닿는 스크립트 엔트리 — **같은 값끼리 한 장면**이다 |
| `dup` | 원문이 같은 묶음. **한 벌만 번역하면 된다**(747줄 절약) |
| `ctrl` | 보존해야 하는 제어코드와 개수 |
| `lines` | 원문 최대 줄 칸수 |
| `jp_tok` | 정본 토큰 원문(`{K:xxx}` 유지). `jp` 는 사람이 읽으라고 한자를 복원한 것 |

## 1. 화자를 어떻게 아는가

텍스트 앞 오퍼코드가 화자를 정한다(`docs/10`).

| 앞 오퍼코드 | 뜻 | 줄 수 |
|---|---|---|
| `03 <id>` | **초상화를 그린다 = 그 인물이 말한다** | 2,424 |
| `6B` | 초상화 없는 창 = 나레이션·안내문 | 559 |
| `05` | switch 로 고른 **파티원별 변형** | 1,706 |
| 그 밖 | 선택지·특수창 | 나머지 |

**`03` 의 id 는 파티 순번과 같다**(`pcstat`/`pcnames` 와 같은 차례).
근거: `02`=「わたくし…ですわ」(셀린), `0B`=「インタビュー」를 말하는 신문기자
(치사토 — `statpc` 의 직업 「新聞きしゃ」와 일치), `08`=「あたし」「ほぇ〜」(프리시스).
`FE` 는 **현재 캐릭터**($C222), `FB` 이상은 파티 슬롯 간접 참조다.

## 2. 파티원 어투 — **실측**과 한국어 지침

「실측」은 그 인물의 원문 전체에서 센 것이다(추정이 아니다).

### 크로드 (id 00, 56줄) — 주인공, 성실
- 실측: `ぼく`×16 / 어미 `よ` `な` `ね`, 가끔 `ですか`
- 한국어: **「나」**, 평이한 반말 — `~야` `~어` `~네` `~지`
- 어른·상급자에겐 `~요`. 과하게 공손하지 않게.

### 레나 (id 01, 84줄) — 상냥, 침착
- 실측: `わたし`/`私` / 어미 `な` `ね` `ですか` `よ`
- 한국어: **「나」**(정중할 땐 「저」), 부드러운 반말 — `~네` `~어` `~야`
- 물음은 `~니?` 보다 **`~어?` `~을까?`** 가 자연스럽다.

### 셀린 (id 02, 63줄) — 우아, 격식 ⭐특징 강함
- 실측: **`わたくし`×16**, **`ですわ`×15 `ですの`×14** `わね` `わよ` `ますわ`
- 한국어: **「저」**, **우아한 존댓말 고정** — `~랍니다` `~예요` `~군요` `~하죠`
- ⛔ **반말로 쓰지 말 것.** 이 인물의 정체성이다.
- 감탄은 `어머` `어머나`.

### 오페라 (id 03, 146줄) — 성숙한 여성, 시원시원
- 실측: `わたし`/`私` / 어미 `ね` `よ` `わよ` `わね` `かしら`
- 한국어: **「나」**, `~야` `~네` `~잖아` `~라구`
- `かしら` → **`~려나` `~일까`**.

### 애슈턴 (id 04, 77줄) — 소심, 사람 좋음
- 실측: `ぼく`×12 / 어미 `ね` `よ` `だよ` `かな`
- 한국어: **「나」**, 조심스러운 반말 — `~네` `~거든` `~려나` `~는데`
- 말끝을 흐리는 느낌(`……`)을 살린다.

### 보우먼 (id 05, 102줄) — 거칠고 호탕
- 실측: `おれ`/`オレ` / 어미 `な`×26 `よ`×25 **`だな` `ぞ` `だろ`**
- 한국어: **「나」**, 거친 반말 — `~군` `~지` `~다구` `~라고`
- `ぞ` → **`~겠어` `~다구`**. 격식 없이.

### 디아스 (id 06, 47줄) — 과묵, 냉정
- 실측: `おれ`/`オレ` / 어미 **`だな`** `な` `ぞ` (줄 수 자체가 짧다)
- 한국어: **「나」**, **짧게 끊는다** — `~군` `~지`
- ⛔ 말을 길게 늘이지 말 것. 원문이 짧으면 번역도 짧게.

### 노엘 (id 07, 39줄) — 온화, 정중
- 실측: `私`/`わたし` / 어미 **`ですか`×14 `ですよ` `ですね` `です`**
- 한국어: **「저」**, 존댓말 고정 — `~습니다` `~군요` `~인가요` `~네요`

### 프리시스 (id 08, 144줄) — 발랄한 소녀 ⭐특징 강함
- 실측: **`あたし`×31** / 어미 `ね` `よ` `さ` `だよ` `かな`
- 한국어: **「나」**, 밝고 빠른 반말 — `~야!` `~잖아` `~거든` `~네`
- 감탄사 **`ほぇ〜` → `호에〜`** 고정. 「무인군(むじんくん)」은 그대로.

### 레온 (id 09, 238줄) — 어린 천재, 약간 건방 ⭐대사 최다
- 실측: `ボク`/`ぼく` / 어미 **`ね`×120** `よ` `な` `だよ` `かな`
- 한국어: **「나」**, 또래보다 어린 말투 + 살짝 건방 — `~야` `~잖아` `~라구` `~거든`
- `〜のさ` → **`~인 거야` `~라는 거지`**.

### 어니스트 (id 0A, 59줄) — 고고학자, 무뚝뚝
- 실측: `おれ`×13 / 어미 `な`×19 `だな` `ぞ`
- 한국어: **「나」**, 무뚝뚝한 반말 — `~군` `~지` `~다`

### 치사토 (id 0B, 70줄) — 신문기자, 활달
- 실측: `私`/`わたし` / 어미 `ね` `よ` **`わよ`** `でしょ`
- 한국어: **「나」**, 활달한 반말 — `~야` `~지` `~잖아` `~라구`
- 취재·기사 관련 낱말이 자주 나온다(인터뷰·특종).

## 4b. ⛔⭐ 직역이 안 붙으면 **구조를 바꾸거나 다른 말로 갈아탄다**

일본어 부사·수식어를 자리만 맞춰 옮기면 한국어에서 **말이 안 붙는** 경우가 있다.
글자 수도 맞고 제어코드도 맞아서 **검사에는 안 걸린다** — 화면에서만 어색하다.

### 실제로 밟은 것 (검수 제보 2026-08-17)

    원문  この遺跡には なまいきにも ガーディアンが あらわれるってしってたか？
    처음  이 유적에는 건방지게도 가디언이 나타난다는 걸 알았나？   ← 어색

`なまいきにも` 는 「분수/격에 안 맞게 감히」라는 **깔보는 투**가 맞다. 하지만
한국어에서 「건방지게도」는 **사람에게만** 붙는다 — 유적이나 몬스터에는 안 붙는다.
(같은 낱말이라도 `chreport` 의 「말버릇 나빠 **건방진 구석**이 보이지만」은
사람 이야기라 아무 문제가 없다. **낱말이 아니라 붙는 대상이 문제다.**)

### 고치는 두 가지 길

1. **어울리는 말로 갈아탄다** — 「주제도 모르고」 「분수도 모르고」
2. ⭐ **어순을 바꾼다.** 우리말은 이런 수식어를 **뒤로 빼서 덧붙이는** 것이
   훨씬 자연스럽고, 비꼬는 맛도 그때 산다.

       실은 이 유적에 가디언이 나온다는군… 어울리지도 않게 말야
                                          └── 뒤로 뺀 수식어

    최종  자네들 실은 이 유적에{01}가디언이 나온다는군{03}주제도 모르고 말이야{03}

⚠ 원문의 의문형(`しってたか？`)을 버렸다. 대신 **「실은」**으로 운을 떼어
  「너희는 모르겠지만」이라는 같은 기능을 살렸다 — 말투의 목적이 같으면
  형태는 바꿔도 된다.

### 훑는 법

사람의 태도를 가리키는 부사가 **사물·현상**에 붙어 있으면 의심한다:

```bash
python - <<'EOF'
# 건방지게 주제넘게 뻔뻔하게 얄밉게 기특하게 갸륵하게 대견하게 가당찮게
# 당돌하게 무례하게 방자하게 괘씸하게 염치없게 …
EOF
```
⇒ 2026-08-17 전수 훑기 결과 **문제는 위 한 줄뿐**이었다(나머지 1건은 사람 이야기).

## 5. 기술 제약 — 번역할 때 반드시 지킨다

1. **제어코드를 원문 그대로 보존한다.** `{01}` 줄바꿈, `{03}` 쪽넘김.
   개수가 달라지면 창이 안 넘어가거나 한 줄로 붙는다. `ctrl` 열로 대조할 것.
2. **한 줄 18칸 이내.** `check_tr` 가 `{01}`·`{03}` 로 끊어서 잰다.
   ⚠ 칸 수는 **바이트 수가 아니다** — 2바이트 글리프도 1칸이다.
3. **`{02}`·`{04}`·`{05}`·`{08}` 은 파라미터를 먹는다.** 뒤 1바이트가 글자가 아니다.
   번역문에 리터럴로 옮기지 말고 **바이트 토큰**(`{02}{3C}`)으로 적는다(`docs/09` §3-1).
4. **`{K:xxx}` 는 원본 글리프를 그대로 쓴다는 뜻**이다. 한국어로 옮길 땐 지운다.
   남겨 두면 그 슬롯이 한글로 회수돼 엉뚱한 글자가 나온다(`encode_ko` 가 막는다).
5. **`stub=SHORT` 55줄은 건드리지 않는다.** 자리가 4바이트가 안 돼 스텁이 안 들어간다.
6. **`dup` 이 같으면 한 벌만 번역**하면 된다 — 나머지는 자동으로 같은 문자열을 가리킨다.

## 6. 아직 정하지 않은 것

- **글리프 용량.** 번역이 쌓이면 슬롯이 모자란다. `docs/06` §2a(`$5A`,`$59` → 1792)를
  번역 도중 한 번은 넣어야 한다. **몇 자가 필요한지는 번역이 끝난 뒤 실측**해서 정한다.
- **NPC 이름.** 대사에 나오는 마을 사람·조직 이름은 아직 정리 안 됐다.
